# ROAM film assets

Place the completed 16:9 H.264 MP4 files here using these exact names:

- roam-intro.mp4 — 30-second opening film. It plays on app launch, then opens the route picker.
- roam-outro.mp4 — 30-second closing film. It plays when a walk reaches its finish, then opens the results screen.

The app checks for these files automatically. Until they are present, it skips the video screens and the demo works normally. The video player starts muted to comply with browser autoplay rules; the player can enable sound or skip.
